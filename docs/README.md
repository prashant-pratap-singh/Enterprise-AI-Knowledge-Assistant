# Documentation

This directory contains technical documentation and deployment guides for the Enterprise AI Knowledge Assistant:

- `ARCHITECTURE.md` (root): High-level system design, data flows, and ER diagrams.
- `DEPLOYMENT.md`: Step-by-step instructions for Docker Compose and Google Cloud Run deployment.
- `API.md`: Detailed OpenAPI reference and schema definitions.
- `EVALUATION.md`: RAG evaluation methodology and benchmark reproduction.
